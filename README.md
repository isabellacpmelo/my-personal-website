## About the project

A modern, responsive personal portfolio website built with Vue 3 and Tailwind CSS. This website showcases my projects, skills, and professional experience with a clean and interactive interface.

## 🚀 Technologies

- **Frontend Framework:** Vue.js 3.5
- **Build Tool:** Vite 5.4
- **Styling:** Tailwind CSS 3.4
- **Utilities:** VueUse
- **Icons:** Bootstrap Icons, Devicon
- **Development Tools:**
  - ESLint for code quality
  - PostCSS & Autoprefixer
  - Vue DevTools
  - Vue Inspector

## 🏗️ Project Structure

```
src/
├── components/            # Vue components
│   ├── UI/               # Reusable UI components
│   ├── Helpers/          # Feature-specific components
│   ├── Project/          # Project-related components
│   └── Sections/         # Main page sections
├── assets/
│   ├── css/             # Global styles
│   └── img/             # Images and icons
│       ├── dev-icons/   # Technology icons
│       ├── language-icon/# Language flags
│       └── projects-cover/ # Project screenshots
├── composables/          # Reusable Vue composables
├── pages/               # Route pages
└── router/              # Vue Router configuration
```

## 🛠️ Development Setup

1. Install dependencies:

```sh
pnpm install
```

2. Start development server:

```sh
pnpm dev
```

3. Build for production:

```sh
pnpm build
```

4. Lint files:

```sh
pnpm lint
```
